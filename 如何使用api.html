《AI 與經濟研究報告》工作坊講義 ｜ Streamlit + API 零環境快速上手指南

🎯 學習目標與架構

本練習旨在幫助學生跳過傳統本地端 Python 環境安裝，直接透過 GitHub + Streamlit Cloud 建構自主更新的動態經濟監測儀表板。

  • 資料來源：FRED API（美國總體經濟數據）與 yfinance（全球金融市場數據）。
  • 雲端架構：GitHub 託管代碼 ➔ Streamlit Community Cloud 一鍵自動部署。
  • 金鑰安全：學習使用 Streamlit Secrets 保護個人 API Key。

🚀 實作三步驟指引

步驟 1：Fork 課程範本儲存庫

  1. 前往課程提供的 GitHub 專案頁面。
  2. 點擊右上角的 Fork 按鈕，將專案複製到自己的 GitHub 帳號底下。

步驟 2：一鍵部署至 Streamlit Cloud

  1. 登入 Streamlit Community Cloud（使用 GitHub 帳號連動）。
  2. 點擊 Create app ➔ 選擇 Yep, I have an app already。
  3. 選取你剛才 Fork 的 Repository，確認 Main file path 為 app.py，最後點擊 Deploy!。

步驟 3：設定安全的 API Key (Streamlit Secrets)

  1. 在開啟的儀表板右下角點擊 Manage app ➔ Settings（齒輪圖示）。
  2. 點選左側的 Secrets 頁籤，貼入以下內容（請替換為你的 FRED API Key）：
FRED_API_KEY = "你的_FRED_API_KEY_字串"
  1. 點擊 Save，網頁將自動重載並帶入數據！

💡 儀表板延伸提示詞 (Prompt Library)

學生可以使用 ChatGPT、Claude 或 Gemini 輔助修改 app.py，實現更多儀表板功能。以下提供可直接複製使用的 Prompt 範本：

📌 提示詞 1：新增金融與總體指標
「我想在目前的 Streamlit 儀表板中新增『黃金現貨價格 (GC=F)』與『日本 10 年期國債殖利率』。請告訴我如何修改 app.py 中的 yfinance 與 FRED 抓取字典，並保持頁面佈局美觀。」
📌 提示詞 2：計算與繪製殖利率倒掛警示
「請協助我修改 Python 程式碼，使用 FRED API 計算『10 年期美債殖利率 (DGS10)』減去『2 年期美債殖利率 (DGS2)』的利差。若利差小於 0，請在 Streamlit 儀表板上顯示警示燈號（紅色 Warning），並繪製利差歷史折線圖。」
📌 提示詞 3：串接 Gemini API 自動生成經濟月報
「我想在 Streamlit 儀表板下方加入一個按鈕『產生 AI 總體經濟摘要』。點擊後會將最新抓取到的 CPI、失業率與利率數值作為上下文，調用 google-genai 介面自動產出一份 200 字的總體經濟短評。請提供完整的範例程式碼。」
📌 提示詞 4：加入資料下載與區間篩選功能
「請幫我的 Streamlit 儀表板加入一個日期範圍選擇器 (st.date_input)，讓使用者能自行選擇圖表的時間區間（例如近 3 個月、近 1 年或全部歷史數據），並在圖表下方提供一個 CSV 下載按鈕 (st.download_button)。」
