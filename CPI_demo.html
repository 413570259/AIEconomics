💡 學習目標：從「抓資料」升級為「經濟學智能戰情室」

當同學成功學會了非同步 fetch()、JSON 解析與 GitHub Pages 靜態部署後，網頁就不再只是一張寫死的報告，而是一個具有「自我持續更新」能力的動態分析工具。以下為同學們展示利用無 Key 或開放 API 可以實現的四大進階階段。

一、 成果展現四大等級 (Competency Roadmap)

Level 1：即時關鍵數據卡片

實現功能： 自動顯示最新通膨率、即時美元匯率、WTI 原油價格卡片。

經濟學意義： 取代人工複製貼上，確保簡報或報告展示時永遠顯示最新發布的權威數字。

Level 2：互動式時間序列圖表

實現功能： 整合 Chart.js，拉取過去 12 到 60 個月的 CPI 物價指數，繪製折線圖與動態選單。

經濟學意義： 動態比較核心 CPI 與 Headline CPI 的基期效應與趨勢傳導。

Level 3：跨指標連動與情境試算

實現功能： 同時抓取匯率、原油與糧食指數，提供滑桿（Slider）讓使用者調整預估參數。

經濟學意義： 計算進口物價對核心商品 CPI 的敏感度分析（Sensitivity Analysis）。

Level 4：AI 智能觀點與自動解讀

實現功能： 自動根據最新月增率（MoM）與年增率（YoY），透過規則或 LLM 產生經濟學短評。

經濟學意義： 自動生成如同高盛或聯準會研究報告般的高品質總體經濟分析短評。

二、 實務情境：經濟專題可以這樣做

1. 匯率與通膨傳導分析（Pass-Through Effect）

結合 Frankfurter API 抓取的 USD/TWD 匯率與美國 CPI，計算公式：

Imported Inflation Contribution = Δ ExchangerateYoY × Import Weight
  • 同學可以在網頁上呈現：匯率波動對核心商品進口成本的推升幅度。

2. 能源通膨（Energy Services）動態預測

透過開放數據串接國際原油走勢（WTI Crude），即時估算下個月汽油與運輸服務 CPI 的月增率情境。範例公式：

Forecast CPIEnergy = β0 + β1 × WTIt + ϵt

三、 免費 API 與工具擴充庫推薦

數據類型 推薦開放 API 源 CORS / 存取屬性 課程專題建議應用
國際匯率 Frankfurter API 完全免 Key / 100% CORS 歐元、日圓、美元即時匯率，進行進口物價分析。
美國月度 CPI jsDelivr / Datasets Open API 完全免 Key / 100% CORS 取得 BLS 歷史 10 年逐月 CPI 指數與年增率。
台灣央行/主計總處 政府資料開放平臺 (data.gov.tw) 免 Key / JSON 格式 台灣消費者物價指數與進出口總額。
視覺化圖表庫 Chart.js / CanvasJS CDN 直接引入 將 JavaScript fetch 回來的陣列轉為動態互動折線圖。

四、 給同學們的專題寫作與展示建議

  • 一鍵展示部署： 所有專題頁面均可免費儲存於 GitHub Pages，直接作為面試與研究所備審的作品集網址。
  • 防錯機制與用戶體驗： 在 JS 中加入 try...catch 與「資料載入中」畫面，展現專業的網頁開發工程素養。
  • 經濟學解釋優先： API 與數據是工具，最核心的是頁面上針對數據變化所撰寫的經濟學解析。
