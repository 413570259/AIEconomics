Fork 專案：點擊本 GitHub 頁面右上角 的 Fork 按鈕，將此專案複製到自己的 GitHub 帳號下。

部署到 Streamlit Cloud：

前往 share.streamlit.io 並使用 GitHub 帳號登入。

點選 Deploy an app -> Use existing repo。

選擇你剛剛 Fork 的 Repository（Main file path 填 app.py），點擊 Deploy！

體驗網頁更新：

部署完成後，打開得到的網址，在側邊欄輸入你的 FRED API Key。

若想修改標題或新增指標，直接在自己 GitHub 網頁上的 app.py 點選筆刷圖示修改並 Commit，網頁會在幾秒內自動更新！
